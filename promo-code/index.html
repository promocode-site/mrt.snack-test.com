마이리얼트립 프로모션코드 사용 조건

  1. 한 결제에 하나 결제 한 건에는 프로모션코드 하나만 들어가며, 세 구간 쿠폰을 겹쳐 쓸 수 없습니다.
  2. ID당 1회 같은 계정으로 다시 쓸 수 없어 큰 예약 한 번에 쓰는 편이 할인액이 큽니다.
  3. 7일 기한 발급한 날부터 7일이 지나면 쿠폰함에서 사라집니다. 여행 일정이 정해진 뒤 발급하세요.
  4. 대상 상품 해외 투어·티켓 기준이며, 항공권은 프로모션코드 대신 카드 즉시할인이 적용됩니다.
  5. 취소 시 처리 예약을 취소하면 사용한 쿠폰이 돌아오지 않을 수 있으니 일정이 확정된 예약에 쓰세요.

할인액·구간

Q

마이리얼트립 프로모션코드는 얼마나 할인되나요?

답결제 금액에 따라 1,000원, 3,000원, 5,000원이 할인됩니다.

5만원·15만원·20만원 이상 구간으로 나뉘며 20만원 이상일 때 가장 큽니다.

Q

14만원 예약이면 어떤 쿠폰이 유리한가요?

답1,000원 쿠폰만 쓸 수 있습니다.

1만원을 더 채워 15만원이 되면 3,000원 쿠폰으로 바뀌지만, 실제로 쓸 상품을 더할 때만 이득입니다.

사용 조건

Q

프로모션코드랑 카드할인 같이 되나요?

답함께 적용됩니다.

쿠폰으로 금액이 먼저 빠지고, 남은 금액에 카드·페이 할인 조건이 다시 계산됩니다.

Q

항공권에도 프로모션코드를 쓸 수 있나요?

답이 프로모션코드는 해외 투어·티켓용입니다.

항공권은 결제 화면의 카드 즉시할인으로 할인받으세요.

Q

쿠폰을 받고 바로 안 써도 되나요?

답발급 후 7일 안에 써야 합니다.

기한이 지나면 쿠폰함에서 사라지니 결제 직전에 발급하세요.
